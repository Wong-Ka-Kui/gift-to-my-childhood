# 主页里的教室

打开项目主页 `/`，登录后在同一个 Three.js 场景中查看原卧室及旁边的教室。两个空间保留独立地板和墙体，中间约 2.7 单位空隙，没有通道连接。

- 教室包含 2 扇窗户、1 块黑板、1 张讲台桌、3 套课桌椅。
- 当前游客的最多 3 个宠物本体进入教室，继续支持双击移动/停止、拖动旋转、自然步态、碰撞避让、只读资料卡和浏览器存档恢复。没有复制第二份宠物。
- 新产生的便便和纸团限制在教室地板安全区域；卧室旧存档中的物品仍可清扫，金币继续保留。
- 主页的「一起看 / 看卧室 / 看教室」只调整相机，不跳转网页。360° 查看、缩放、平移继续可用。
- 教室建模源码为 `src/classroom/model.ts`，摆放算法为 `src/classroom/campus.ts`；原教室资产保留在 `models/little-classroom.glb`。
- 已取消独立教室页面与多入口构建。运行 `npm run dev` 后直接访问主页即可。
