# 家旁边的小教室

在同一个 Three.js 场景中并列展示原卧室和新教室。两个房间有独立的地板、墙体，之间留有约 3.2 单位空隙，无通道连接。卧室恢复当前游客的家具布局；教室读取同一浏览器、同一网站地址下的最多 3 个宠物存档，保留名字与确认时的模型朝向，安排在桌椅旁的安全地板位置。宠物在此预览中静止站立。预览只读取存档，不写入或迁移原房间数据。

- 开发：在项目根目录运行 `npm run dev`，访问 `/classroom/`。
- 构建：`npm run build` 同时生成原主页和 `dist/classroom/index.html`。
- 模型：`models/little-classroom.glb`。也可在预览页面点击「下载模型 .GLB」重新生成。
- 源码：`src/classroom/model.ts` 为教室模型，`src/classroom/campus.ts` 为组合场景与安全摆放，`src/classroom/main.tsx` 为预览、存档加载和教室导出。

包含 2 扇窗户、1 块黑板、1 张讲台桌、3 张课桌和 3 把椅子。桌椅朝向黑板，物件按名称和 `userData.kind` 分组。整体宽 10、深 8、墙高 3.8；Y 轴向上，地板位于 Y=0 附近。卡通剖面场景保留前墙和左墙，便于查看内部。

操作：左键或单指拖动旋转，滚轮或双指缩放，右键拖动平移。遮挡视线的墙面在预览中自动淡出；导出的 GLB 始终包含所有墙体、家具与嵌入贴图。导出不包含相机、灯光或交互脚本，在其他软件中使用时需自行设置灯光。

「一起看 / 看卧室 / 看教室」切换取景；「重置视角」回到并列全景。「下载教室 .GLB」仅导出原教室资产，不包含宠物和卧室。如果页面提示没有宠物，请使用原先导入模型的浏览器打开同一地址；不同浏览器、域名或端口的存档不共享。
