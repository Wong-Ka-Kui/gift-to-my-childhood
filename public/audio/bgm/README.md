# 背景音乐

当前曲目：`Sunny Afternoon Together.mp3`（约 2 分 55 秒），以固定文件名保存：

```text
public/audio/bgm/main.mp3
```

进入房间后首次点击或按键会尝试开始循环播放，也可以点击背景音乐控件播放。浏览器会限制未经交互的自动播放。首次使用默认音量为 35%，控件支持暂停、静音和调节音量；音量会保存在当前浏览器中。

音乐地址随项目部署路径解析，支持 Garden 的 `/seed/<项目路径>/`。构建和 Garden 打包均包含音乐文件，部署后重新构建也会保留。要更换曲目，替换 `main.mp3` 后重新构建即可。
