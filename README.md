# home

## 独立黑白棋试玩

运行 `npm run dev` 后访问 [黑白棋](http://127.0.0.1:5173/othello/index.html)。基于 MIT 开源项目 [Flip Buddies](https://github.com/deifos/Othello)，提供经典/增强模式的人机对战、角色、音效及本地存档。联网房间和排行榜暂未接入。

游戏入口、样式、依赖与存档均独立于房间和手绘角色。源码在 `games/othello/`，静态产物在 `public/othello/`；开发、测试及重新构建方法见 [游戏说明](games/othello/README.md)。

一个可直接验证 3D 宠物导入的卡通卧室场景：浅黄格纹地板、两面浅蓝矮墙、两张上下铺、窗户、四人长书桌和四个凳子。网页名称为 `home`。

## 运行

Node.js 22.12+ 或 24 LTS：

```sh
npm ci
npm run dev
```

浏览器打开终端显示的网址。`npm run build` 构建，`npm test` 运行导入校验、宠物放置和移动避让等测试。

## 游客进入与手绘角色

- 游戏入口：`/`。首次打开先输入 1–24 个字符的名字，形象随名字变化，点击「游客进入」后进入房间，无需密码。
- 手绘角色入口：`/hand-drawn-character/index.html`，输入不同用户名生成不同角色。
- 房间右上角显示用户名和生成角色的头像；名字、头像、固定游客 ID 与宠物存档一起保存在 IndexedDB。刷新或关闭后再打开同一浏览器、同一网址会自动恢复。
- 角色页面源文件及说明在 `public/hand-drawn-character/`，开发和构建后均可直接访问上述 HTML 路径。
- 角色页面通过 `?mode=guest` 嵌入游客入口，复用原有形象生成逻辑并截取角色头像。独立打开原地址仍保留演示功能。
- 数据库从 v1 升级到 v2 时保留已有宠物；第一次确认游客身份时，在同一事务中绑定旧存档。姓名只用于展示和生成形象，不是跨设备账号，也不要求全局唯一。
- 只有事务写入成功才完成游客进入或宠物导入；保存失败可保留输入后重试。模型恢复失败不会自动删除存档。

## 移动家具

- 自由活动时双击上下铺、长书桌或圆凳进入移动状态，单击不会移动。梯子及桌面装饰随家具整体移动；窗户固定在墙上。
- 双击后移动鼠标，再单击放置；也可以第二次按下时按住拖动，松开放置。触屏支持双击后拖动。
- 移动中家具略微抬起，地板显示投射阴影和占地轮廓；与家具、宠物重叠或越出地板时，模型变红。
- 合法位置确认摆放；非法位置松开或点击后返回原位。Esc、底部「取消」、切出页面或触摸中断也会取消。
- 编辑时宠物暂时停下，确认后按新的家具位置避让，原有宠物移动/停止状态保留。家具位置自动写入当前游客的本地存档，刷新恢复。

## 导入

- 点击「导入宠物」或将文件拖入房间，填写名字、性别、年龄、MBTI 和选填介绍，再确认进入家园。
- 当前页面最多放置 4 只宠物，达到上限后导入按钮置灰，拖入文件也不能继续添加。新增宠物不会替换已有宠物。
- 宠物模型文件和介绍资料会自动保存到当前浏览器的 IndexedDB；下次打开同一网址会恢复已导入的宠物。清理浏览器站点数据或换设备后需要重新导入；当前存档只在本机，不会自动同步给其他开发者。
- 第一只优先出现在房间正中间；若家具占位，则选择离中心最近的安全位置。后两只随机出现在房间内，避开家具和其他宠物；活动时也保留彼此的安全间距。
- 资料卡中的模型默认正面展示；水平拖动选择入园时的朝向，确认后保留相对镜头的朝向。名字以小号、半透明标签显示在宠物头顶，随宠物移动和房间镜头旋转、缩放。
- 支持 GLB，以及一个 glTF 配套的 BIN 和 PNG/JPEG/WebP 贴图；推荐把贴图打包为 GLB。
- 总计最多 100 MB、100 个文件。支持 Draco / Meshopt 网格解码；不支持 USDZ、FBX、OBJ 或 KTX2 纹理。
- 本次在下载目录找到的是 `奶蛙.glb`，未找到 `奶蛙.usdz`。验证使用实际的 GLB 文件，不将文件改名假装兼容 USDZ。
- 模型保存在浏览器本地，不会上传模型或把用户模型放进 GitHub。网址的协议、主机或端口变化属于不同站点，存档不会互通。
- 原始文件不修改，只对场景内的模型居中、等比缩放和移动。
- 按住 Shift 水平拖动任意宠物可调整其水平朝向；双击该宠物可独立切换自动运动和原地停止，触屏支持双击。停止时拖动旋转不会恢复行走。Three.js 的竖直轴为 Y，因此水平转身实际绕 Y 轴实现。
- 奶蛙保持长时间休息、偶尔散步，移动有加速、减速和缓慢转身；双足交替抬起落地，停下后自然收脚。
- 房间默认支持 360° 查看：拖动空白处旋转视角，滚轮或双指缩放，不提供拖动平移或查看模式开关。墙面根据当前视角渐变显隐；底部可切换卧室、教室和全景，也可点击「回到默认视角」恢复初始取景。宠物转身、双击移动家具和点击清扫保持可用；模型资料卡或家具编辑期间暂停相机操作。
- 当前奶蛙无骨骼和内置动画，运行时根据双足结构绑定轻量骨骼，以世界坐标固定支撑脚、两节腿部 IK 和水平脚掌驱动迈步；家具和边界避让范围包含步幅。切到后台时停止推进，返回后不跳跃位移。源模型文件不变。
- 自动朝向和双足识别依据脚踝分布与脚尖方向，当前已用奶蛙验证；非标准体型不能保证自动识别正面或生成合适步态。已有命名 walk/locomotion 的模型优先使用内置动作，无法识别的模型保留原网格，不强制套用双足变形。

技术：React、TypeScript、Vite、Three.js。`src/components/Room.tsx` 创建房间；`src/lib/model.ts` 读取模型；`src/lib/assets.ts` 校验资源；`src/lib/wander.ts` 控制随机行走。

## 游戏时间与昼夜

- 家园首次启用时从第 1 天 08:00 开始；现实 1 秒推进游戏 1 分钟，现实 24 分钟完成一个昼夜。左上角显示日期、时间和时段，教室挂钟同步走时。
- 时间起点存入 IndexedDB 的 `session.timeOrigin`。旧游客存档首次打开时自动补齐；刷新、关闭页面和离线期间继续按现实时间推进，同一浏览器的多个标签页共用起点。
- 清晨 05:00–07:00、白天 07:00–17:00、黄昏 17:00–19:00、夜晚 19:00–05:00。天空、环境光、太阳位置和影子连续变化；室内暖灯在傍晚渐亮、清晨渐灭。
- 卧室和教室共五扇窗带有窗洞、窗框、玻璃反光及动态窗景；窗外云朵、山丘、太阳和月亮星空随时间变化，包含旋转时出现的背面窗户。
- 宠物作息按游戏时间执行：10:00–19:00 在教室，其他时间在家；刷新后按当前时间恢复。两栋建筑尚未连接，切换时淡出、淡入到安全空位。清扫奖励仍按有效游玩时间计算。
- 顶部保留隐藏吊灯的暖色向下照明，不渲染灯罩、灯杆或壁灯实体。
- 直接拖放宠物到空凳附近，会放到安全的椅旁位置并坐下；房间圆凳、教室椅子均可用。已占用或被家具挡住的座位不能使用，非法落点回到原位。奶蛙会随机寻找可到达的空位，坐一会儿再起立散步；双击坐着的奶蛙可提前起立。
- 奶蛙坐姿由双腿骨骼弯曲生成；无可识别双足的其他模型使用轻微压低的休息姿态，不能保证所有外部模型都能生成拟人的坐姿。

## 四人配置与固定作息

- 教室为四套桌椅，卧室为两张上下铺（四个独立床位）、一张长书桌和四个圆凳。旧存档保留宠物；旧家具布局不适合新家具时使用新默认布局。
- 游戏时间 23:30–次日 07:00 强制上床；10:00–12:00、13:30–17:00、18:00–19:00 强制入座上课。每只宠物分配不同床位或座位，时段结束恢复自由活动。规定时段不允许拖离位置或编辑家具。
- 自由活动时，把奶蛙直接拖到目标床垫上可睡觉，上下层分别识别；双击可起床。上床、下床采用淡出淡入，避免从上铺穿过床板落到地面；原始模型文件不变。
- 行为日记使用电脑的现实本地日期，今天之后的日期禁用、不生成记录；不能翻到未来月份。跨日期或重新聚焦会更新截止日期。日记内容仍使用既有演示记录生成逻辑，尚未改为实际事件存档。
- 左侧日记入口移到靠下位置，伙伴栏在小屏上可滚动，避免四个头像与入口重叠。
