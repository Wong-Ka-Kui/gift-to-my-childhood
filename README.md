# home

一个可直接验证 3D 宠物导入的卡通卧室场景：浅黄格纹地板、两面浅蓝矮墙、高架床、窗户、桌子和凳子。网页名称为 `home`。

## 运行

Node.js 22.12+ 或 24 LTS：

```sh
npm ci
npm run dev
```

浏览器打开终端显示的网址。`npm run build` 构建，`npm test` 运行导入校验测试。

## 导入

- 点击「资源导入」或将文件拖入房间。
- 支持 GLB，以及一个 glTF 配套的 BIN 和 PNG/JPEG/WebP 贴图；推荐把贴图打包为 GLB。
- 总计最多 100 MB、100 个文件。支持 Draco / Meshopt 网格解码；不支持 USDZ、FBX、OBJ 或 KTX2 纹理。
- 本次在下载目录找到的是 `奶蛙.glb`，未找到 `奶蛙.usdz`。验证使用实际的 GLB 文件，不将文件改名假装兼容 USDZ。
- 导入仅在当前页面内存中显示，刷新恢复空房间；不会上传模型，也不会把用户模型放进 GitHub。
- 原始文件不修改，只对场景内的模型居中、等比缩放和移动。
- 单击并水平拖动奶蛙可调整其水平朝向；双击奶蛙可切换自动运动和原地停止。Three.js 的竖直轴为 Y，因此水平转身实际绕 Y 轴实现。
- 奶蛙约 70% 时间静止站立、30% 时间移动，会避开家具并在房间边界内活动；当前模型没有腿部迈步动画。
- 房间镜头从固定斜视角观察，支持拖动平移和滚轮缩放，禁止旋转视角。房间地板为 12×12，墙高约 3.3；根据模型旋转后的最大水平半径留出行走边距。
- 当前奶蛙无骨骼和内置动画，行走是整体平移与转向，没有腿部迈步动画。切到后台时停止推进；返回后不跳跃位移。

技术：React、TypeScript、Vite、Three.js。`src/components/Room.tsx` 创建房间；`src/lib/model.ts` 读取模型；`src/lib/assets.ts` 校验资源；`src/lib/wander.ts` 控制随机行走。
